# David Tennant Character Sort — 4択 + 画像共有版

## 変更点
- 1問につき4キャラクター表示
- 4人の中から1人を選択
- スマホは2×2、PCは4列
- 結果TOP9をPNG画像として自動生成
- 「Xで画像付き共有」
  - Web Share API対応スマホ: 共有シートからXを選ぶと画像ファイルを渡せます
  - 非対応PC: PNGを自動保存し、X投稿画面を開きます（画像添付のみ手動）
- 「結果画像を保存」ボタン追加

## GitHub Pagesへの反映
リポジトリ直下の `index.html` / `style.css` / `app.js` をこのZIP内のものに上書きしてください。
URLは変わりません。

## 画像
`images/` に app.js で指定しているファイル名で画像を置いてください。
同一GitHub Pages配下の画像であれば、結果画像生成にもそのまま使えます。
